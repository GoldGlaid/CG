Лабораторная работа No1: Основы 3D-графики 
 
Цель лабораторной работы: 
В  этой  лабораторной  работе  вы  познакомитесь  с  основами  3D-графики: 
построением  простых  3D-объектов,  проекцией  на  2D-плоскость,  а  также 
научитесь  работать  с  матрицами  перспективы,  ортографической  проекции  и 
аффинными преобразованиями. 
 
Требования: 
Вы  должны  использовать  Vulkan,  GLFW  и  ImGUI.  Стартовый  код  уже  всё  это 
содержит, но если хотите попробовать без него, то я похвалю за отвагу! 
P.S. Если хотите программировать на Direct3D под Windows, то используйте 
именно Direct3D 12, потому что он с Vulkan похож 
 
Программа  должна  работать  в  реальном  времени,  с  возможностью 
динамической смены проекции и трансформаций объектов. 
Все  объекты  должны  корректно  отрисовываться  с  учетом  проекции  и  иметь 
возможность взаимодействия с пользователем. 
 
Вы  должны  сделать  задание  своего  варианта  полностью  по  условию  на 
базовую оценку 4. Любой невыполненный пункт из варианта снижает оценку на 
пол-балла.  Чтобы  повысить  оценку,  нужно  сделать  два  дополнительных 
задания  из  списка  ниже  после  вариантов.  Каждое  выполненное 
дополнительное задание даёт пол-балла. 
 
Пример #1: У вас выпал вращающийся куб, но не сделана анимация вращения, 
как  требуется  по  условию  варианта  и  не  выполнены  доп.  задания  – 
итоговая оценка 3.5 
 
Пример #2: Вы выполнили все пункты условия по вашему варианту и сделали 
одно дополнительное задание – итоговая оценка 4.5 
 
 
Варианты: 
1.  Вращающийся куб. Отрисовать куб (8 вершин, 36 индексов для 
треугольников). Задать фиксированный цвет через uniform/push constant. 
Перспективная проекция. Анимация: куб вращается вокруг Y-оси. 
Добавить UI элементы для изменения скорости вращения. 
2.  Сфера с пульсирующим масштабом. Сгенерировать сферу (~100 
вершин, параметрические уравнения). Цвет фиксированный. 
Перспективная проекция. Анимация: сфера масштабируется по 
синусоиде (sin(time)). Добавить элементы UI для поворота камеры. 
3.  Пирамида с иерархическими трансформациями. Отрисовать 
пирамиду (5 вершин: квадратное основание + вершина). Создать две 
пирамиды: одна статичная, вторая "дочерняя" (масштабированная и 
смещенная относительно первой). Использовать стек матриц для 
иерархии. Цвет фиксированный. Анимация: вращение всей системы 
вокруг Z-оси. Масштаб и радиус орбиты задаются с помощью UI 
элементов 
4.  Цилиндр с ортографической проекцией. Сгенерировать цилиндр (~50 
вершин, без крышек). Цвет задается через uniform/push constant. 
Использовать ортографическую проекцию. Анимация: цилиндр 
перемещается по траектории (например, по окружности). Добавить UI 
элементы для изменения радиуса траектории. 
5.  Тор с изменением цвета. Сгенерировать тор (~200 вершин, двойной 
цикл). Цвет меняется через uniform/push constant по времени (например, 
sin(time) для RGB-компонент). Перспективная проекция. Анимация: тор 
вращается вокруг своей оси. Добавить UI элемент для изменения угла 
обзора и скорости вращения 
6.  Конус с множественным рендерингом. Отрисовать несколько конусов 
(больше 2) (вершины по кругу + вершина) с разными позициями и 
масштабом. Цвет фиксированный. Анимация: конусы вращаются 
независимо. Фиксированная камера. Добавить UI элемент для 
изменения скорости вращения 
7.  Кубоид с пользовательским масштабом. Отрисовать кубоид с 
параметрами размеров, задаваемыми пользователем. Цвет 
фиксированный. Перспективная проекция. Анимация: кубоид 
"пульсирует" по Y-оси (масштабирование). Добавить элементы UI для 
изменения позиции и размеров. 
8.  Октаэдр с двойным вращением. Отрисовать октаэдр (8 треугольных 
граней). Цвет задается через uniform/push constant. Перспективная 
проекция. Анимация: октаэдр вращается вокруг X и Y осей 
одновременно. Добавить элемент в UI для изменения скорости 
вращения. 
9.  Комбинация куба и сферы. Отрисовать сцену с кубом и сферой 
(отдельные вершинные и индексные буферы). Разные цвета через 
uniform/push constant. Куб статичный, сфера "орбитирует" вокруг куба по 
круговой траектории. Перспективная проекция. Анимация: орбитальное 
движение. 
10. Построение 3D-сцены с несколькими объектами. Постройте сцену, 
содержащую куб, пирамиду и сферу. Перспекитвная проекция. Цвет у 
каждой фигуры разный. Добавьте UI элементы для позиционирования и 
изменения цвета для каждой фигуры 
 
Дополнительные задания: 
1.  Интерполяция цвета между вершинами. Модифицировать вершинный 
буфер,  добавив  к  каждой  вершине  атрибут  цвета  (RGB).  В 
vertex-шейдере  передать  цвет  во  fragment-шейдер  для  интерполяции. 
Например,  для  куба  можно  задать  разные  цвета  углам,  чтобы  получить 
градиентный эффект. 
2.  Сложная  траектория  анимации.  Заменить  простую  анимацию 
(например,  вращение или синусоидальное движение) на более сложную 
траекторию.  Например,  объект  движется  по  спирали,  эллипсу  или 
траектории в форме восьмерки (используя параметрические уравнения). 
Реализовать через модельную матрицу с зависимостью от времени. 
3.  Переключение между перспективной и ортографической проекцией. 
Добавить  возможность  переключения  между  перспективной  и 
ортографической  проекцией  с  помощью  элементов  UI.  Реализовать 
через изменение проекционной матрицы. 
4.  Добавить к сцене третий объект  (например, еще один куб, сферу или 
пирамиду),  связанный  иерархически  с  существующими.  Например,  к 
вращающейся  пирамиде  добавить  маленький  куб,  который  вращается 
вокруг  "дочерней"  пирамиды.  Иерархия  будет  реализована композицией 
матриц  (перемножение  матрицы  трансформации  дочернего  и 
родительского  объекта.  Каждый  объект  с  разным  цветом  (через 
uniform/push constant). 
5.  Анимация с паузой и реверсом.  Добавить  управление  анимацией:  UI 
элемент  для  паузы/возобновления  и  UI  элемент  для  реверса 
направления  (например,  изменение  знака  угловой  скорости  вращения). 
Реализовать  через  переменную  времени  и  модификатор  направления в 
модельной матрице.
