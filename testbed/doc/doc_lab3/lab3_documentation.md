## Математические основы текстурирования

### UV координаты

UV координаты - это двумерные координаты, которые связывают точки на поверхности 3D объекта с точками в 2D текстуре. 

**Математическое определение:**
- U координата: горизонтальная координата в текстуре, диапазон [0, 1]
- V координата: вертикальная координата в текстуре, диапазон [0, 1]

Для вершины с UV координатами `(u, v)`:
- `u = 0` соответствует левому краю текстуры
- `u = 1` соответствует правому краю текстуры
- `v = 0` соответствует верхнему краю текстуры (или нижнему, в зависимости от системы координат)
- `v = 1` соответствует нижнему краю текстуры

### Интерполяция UV координат

При растеризации треугольника, UV координаты интерполируются между вершинами:

```
u_fragment = w0 * u0 + w1 * u1 + w2 * u2
v_fragment = w0 * v0 + w1 * v1 + w2 * v2
```

где `w0, w1, w2` - барицентрические координаты фрагмента в треугольнике, и `w0 + w1 + w2 = 1`.

### Преобразование UV в координаты текстуры

Для текстуры размером `width × height` пикселей, координаты пикселя вычисляются как:

```
pixel_x = floor(u * width)
pixel_y = floor(v * height)
```

## Загрузка и создание текстур

### Формат изображения

Изображения загружаются из PNG файлов в формате RGBA8 (8 бит на канал, 4 канала: Red, Green, Blue, Alpha).

### Конвертация в формат Vulkan

Vulkan использует формат `B8G8R8A8_UNORM`, где порядок байтов в памяти (little-endian):
- Младший байт: Blue
- Второй байт: Green
- Третий байт: Red
- Старший байт: Alpha

**Математическое преобразование:**

Для пикселя с компонентами `(R, G, B, A)` в диапазоне [0, 255]:

```
pixel_value = (A << 24) | (R << 16) | (G << 8) | B
```

где `|` - побитовая операция OR, `<<` - побитовый сдвиг влево.

### Создание изображения в Vulkan

Изображение создается с параметрами:
- **Формат:** `VK_FORMAT_B8G8R8A8_UNORM`
- **Использование:** `VK_IMAGE_USAGE_TRANSFER_DST_BIT | VK_IMAGE_USAGE_SAMPLED_BIT`
- **Layout:** `VK_IMAGE_LAYOUT_SHADER_READ_ONLY_OPTIMAL` (после загрузки данных)

## Сэмплирование текстур

### Линейная фильтрация

При сэмплировании текстуры используется линейная интерполяция между соседними пикселями.

Для координаты `(u, v)` в текстуре размером `W × H`:

1. Вычисляем координаты пикселей:
   ```
   x = u * W - 0.5
   y = v * H - 0.5
   ```

2. Определяем четыре соседних пикселя:
   ```
   x0 = floor(x), x1 = x0 + 1
   y0 = floor(y), y1 = y0 + 1
   ```

3. Вычисляем веса интерполяции:
   ```
   fx = x - x0
   fy = y - y0
   ```

4. Билинейная интерполяция:
   ```
   color = lerp(
       lerp(texel(x0, y0), texel(x1, y0), fx),
       lerp(texel(x0, y1), texel(x1, y1), fx),
       fy
   )
   ```

где `lerp(a, b, t) = a * (1 - t) + b * t` - линейная интерполяция.

### Адресация текстур

**Режим REPEAT:**
```
u_wrapped = u - floor(u)
v_wrapped = v - floor(v)
```

Это позволяет текстуре повторяться бесконечно.

**Режим CLAMP_TO_EDGE:**
```
u_clamped = clamp(u, 0.0, 1.0)
v_clamped = clamp(v, 0.0, 1.0)
```

Координаты ограничиваются границами текстуры.

## Нетривиальное сэмплирование

### Волновое искажение UV координат

Добавляется синусоидальное искажение для создания эффекта волн:

**Математическая формула:**

```
modified_uv.x = u + sin(v * frequency + time * speed) * strength
modified_uv.y = v + cos(u * frequency + time * speed) * strength
```

где:
- `frequency` - частота волн (количество волн на единицу UV координаты)
- `time` - текущее время для анимации
- `speed` - скорость анимации волн
- `strength` - амплитуда искажения (сила эффекта)

**Параметры в реализации:**
- `wave_strength = 0.02` - слабое искажение для сохранения читаемости текстуры
- `wave_frequency = 2.0` - частота волн
- `speed = 1.0` - скорость анимации

### Вращение UV координат

UV координаты вращаются вокруг центра `(0.5, 0.5)`:

**Математическое преобразование:**

1. Смещаем координаты в центр:
   ```
   centered_uv = uv - vec2(0.5, 0.5)
   ```

2. Вычисляем угол вращения:
   ```
   angle = length(position.xy) * scale_factor + time * rotation_speed
   ```

3. Применяем матрицу поворота:
   ```
   rotated_uv = [
       [cos(angle), -sin(angle)],
       [sin(angle),  cos(angle)]
   ] * centered_uv
   ```

4. Возвращаем координаты:
   ```
   modified_uv = rotated_uv + vec2(0.5, 0.5)
   ```

**В матричной форме:**
```
[modified_u]   [cos(θ)  -sin(θ)] [u - 0.5]   [0.5]
[modified_v] = [sin(θ)   cos(θ)] [v - 0.5] + [0.5]
```

где `θ = angle` - угол поворота.

## Множественные материалы и дескрипторные наборы

### Структура материала

Каждый материал содержит:
- **Albedo текстура** - основной цвет материала
- **Specular текстура** - карта бликов (модулирует интенсивность отражения)
- **Emissive текстура** - карта свечения (добавляет свет без освещения)
- **Сэмплеры** - параметры фильтрации для каждой текстуры

### Дескрипторные наборы

В Vulkan нельзя изменять дескрипторный набор во время выполнения команд рисования. Поэтому для каждого материала создается отдельный дескрипторный набор.

**Структура дескрипторного набора:**
- Binding 0: `SceneUniforms` (uniform buffer) - общие параметры сцены
- Binding 1: `ModelUniforms` (uniform buffer dynamic) - параметры модели
- Binding 2: `PointLightsBuffer` (storage buffer) - массив точечных источников света
- Binding 3: `albedo_texture` (combined image sampler) - основная текстура
- Binding 4: `specular_texture` (combined image sampler) - текстура бликов
- Binding 5: `emissive_texture` (combined image sampler) - текстура свечения

### Привязка дескрипторных наборов

При рендеринге каждой модели выбирается соответствующий дескрипторный набор:

```
material_index = model.material_index
descriptor_set = material_descriptor_sets[material_index]
vkCmdBindDescriptorSets(..., &descriptor_set, ...)
```

## Интеграция текстур с освещением

### Модель Блинн-Фонга

Используется модифицированная модель Блинн-Фонга с поддержкой текстур.

### Albedo (диффузное отражение)

Цвет материала вычисляется как произведение текстуры и цвета материала:

```
material_albedo = albedo_texture.rgb * material.albedo_color
```

Если `material.albedo_color = (1, 1, 1)`, текстура отображается без тонирования.

### Specular (зеркальное отражение)

Интенсивность бликов модулируется specular текстурой:

```
material_specular = material.specular_color * specular_texture.rgb
```

### Emissive (свечение)

Emissive текстура добавляет свет без учета освещения:

```
final_color += emissive_texture.rgb
```

### Полная формула освещения

**Рассеянное освещение:**
```
I_ambient = ambient_light_intensity * material_albedo
```

**Направленное освещение (солнце):**
```
N = normalize(normal)
L = normalize(-sun_light_direction)
V = normalize(view_position - fragment_position)
H = normalize(V - L)  // Полувектор

diffuse = max(0, dot(N, -L)) * material_albedo
specular = pow(max(0, dot(N, H)), shininess) * material_specular

I_directional = (diffuse + specular) * sun_light_color
```

**Точечные источники света:**
Для каждого точечного источника:
```
L = normalize(light_position - fragment_position)
distance = length(light_position - fragment_position)
attenuation = light_intensity / (distance² + ε)

H = normalize(L + V)

diffuse = max(0, dot(N, L)) * material_albedo
specular = pow(max(0, dot(N, H)), shininess) * material_specular

I_point = (diffuse + specular) * light_color * attenuation
```

**Итоговый цвет:**
```
final_color = I_ambient + I_directional + Σ(I_point) + emissive_texture.rgb
```

## Реализованные особенности

### 1. Загрузка текстур из PNG

Используется библиотека `lodepng` для декодирования PNG файлов. Изображения конвертируются из RGBA8 в формат B8G8R8A8_UNORM для Vulkan.

### 2. Создание сэмплеров

Сэмплеры создаются с параметрами:
- **Фильтрация:** LINEAR (линейная интерполяция)
- **Адресация:** REPEAT (повторение текстуры)
- **Анизотропия:** Включена (улучшает качество текстур под углом)

### 3. Множественные материалы

Реализованы 4 материала:
- Материал 0: Золотая текстура (для первого тора)
- Материал 1: Текстура Геральта (для куба)
- Материал 2: Деревянная текстура (для пола)
- Материал 3: Золотая текстура (для маленьких торов)

### 4. Нетривиальное сэмплирование

Реализовано волновое искажение и вращение UV координат с возможностью отключения через флаг `disable_uv_distortion`.

### 5. Сетка досок на полу

Пол состоит из множества маленьких досок, расположенных в сетке. Позиционирование вычисляется так, чтобы доски точно соприкасались:

```
start_x = -actual_size_x / 2.0f + board_width / 2.0f
pos_x = start_x + board_width / 2.0f * x
```

где `x` - индекс доски в сетке.
